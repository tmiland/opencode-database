# Knowledge Index

The memory bank's table of contents. When you add, rename, or remove a file
under `knowledge/`, update this list.

- [user.md](user.md) — user preferences, environment, tooling, workflows
- [learnings.md](learnings.md) — general technical lessons that apply across projects
- [projects/](projects/) — one file per project directory (`projects/<dir-name>.md`);
  `projects/_TEMPLATE.md` is the starting point for new project files
